# Beispiel-Richtlinie (Format-Referenz)

<a id="geltungsbereich"></a>
## 1. Geltungsbereich
Dies ist eine unverfängliche Beispiel-Richtlinie als Format-Referenz für eigene oder lizenzierte Inhaltspakete in `ins-isms`.

## 2. Beispiel-Regelungen
- Jedes Dokument kann über `<a id="..."></a>`-Anker direkt aus dem Statement of Applicability (SoA) referenziert werden.
- Beim Import über `/exports` oder `SEED_DIR` wird die Richtlinie zunächst als Entwurf (`0.1`) angelegt und überschreibt niemals bereits freigegebene Versionen.
