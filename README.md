# ins-isms

`ins-isms` is an opinionated Information Security Management System (ISMS) written in Rust implementing **ISO 27001:2022** and **NIS2**. It is primarily designed for German SMEs pursuing ISO 27001:2022 certification and NIS2 / BSIG compliance.

> **WARNING: Early Development – Not for Production Use!**  
> This software is still under active development. Data structures and interfaces may change at any time, which may lead to data loss. Testing and evaluation are explicitly welcome; however, this software is **not approved for production use**.
